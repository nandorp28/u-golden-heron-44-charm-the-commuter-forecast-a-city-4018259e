One line of weather forecast, at most 140 characters, for a city that does not exist — written to make a bored commuter smile on the way to work.

> Forecast for Mizzlewick: sunny intervals, 19°C, and a 90% chance the train is cancelled — pack patience, it counts as carry-on.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), validating it first: a single line, 1–140 characters by code points, no leading/trailing whitespace, no double spaces, no trailing newline. The program reads the file back and fails unless it is byte-identical to the entry.
